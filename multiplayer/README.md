# Онлайн-поединки
Сервер multiplayer/server.js использует Node.js без сторонних зависимостей.
Локально: npm run duel:server. Проверка: GET /health.
Для локального браузера задайте ALLOW_LOCAL_ORIGINS=true; в production оставьте только ALLOWED_ORIGINS с HTTPS-origin сайта.
Создатель комнаты получает случайный персональный токен, второй игрок входит по шестизначному коду. Токены передаются в заголовке Authorization, имена не дают права доступа.
Десять общих заданий: четыре фрагмента рисунка собираются в порядке верхний левый, верхний правый, нижний левый, нижний правый. Перед стартом обоим игрокам даётся общий отсчёт. Раунд длится до 20 секунд. Первая правильная отправка приносит очко и закрывает раунд; после неправильной отправки в текущем раунде отвечать повторно нельзя. В конце сравниваются очки за первые правильные ответы, при равенстве — ничья.
Счёт и время определяет сервер по моменту получения запроса; задержка сети включена во время. Онлайн-поединки не меняют локальный XP.
Клиент опрашивает сервер по HTTPS, сервер разрешает только указанные origins. Нет аккаунтов и рейтинга. Комнаты хранятся в памяти процесса, удаляются через 30 минут неактивности и теряются при перезапуске сервера. Render Free может засыпать и запускаться около минуты. Сервис рассчитан на небольшое число одновременных игроков, без гарантий турнирной защиты от автоматизации.
Иллюстрации — демонстрационные пазлы по мотивам эмбусэн Пинан и учебных кю-связок. Это сборка картинки, а не подтверждение исполнения ката; схемы требуют тренерской проверки и не представлены как официальные требования.
## Render
1. Подключите репозиторий в Render и создайте Blueprint из render.yaml.
2. Дождитесь Live и проверьте https://ВАШ-СЕРВИС.onrender.com/health.
3. На сайте откройте Поединок, укажите HTTPS-адрес сервера и создайте комнату.
4. Отправьте второму игроку ссылку-приглашение или адрес сервера и код комнаты.
Секреты не нужны. Адрес сервера публичный, сохраняется на устройстве и включается в приглашение.
