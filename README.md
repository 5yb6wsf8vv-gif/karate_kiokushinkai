# Киокушинкай: тренажёр

Русскоязычное приложение для начинающих без регистрации. Адаптивный интерфейс, 10 японских терминов, 6 ознакомительных технических тем, карточки, выбор перевода, упражнение на слух, интервальное повторение, короткое занятие и статистика.

## Запуск

Нужен Node.js 20.19+ или 22.12+ (в облачной среде проверено на Node.js 24).

```sh
npm ci --cache /tmp/kyokushin-npm
npm run dev -- --port 5173
```

`npm run build` создаёт статический сайт в `dist`. `npm run preview` запускает локальную проверку сборки.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют установленный `/usr/bin/chromium`. Для другого пути задайте `CHROMIUM_PATH`. Проверяются мобильный и настольный интерфейсы, переходы и история браузера, сохранение после перезагрузки, выбор программы, ошибки ответа, срок повторения и завершение занятия.

## Данные и повторение

Прогресс сохраняется в localStorage браузера под ключом `kyokushin-v1`, отдельно для каждого адреса сайта и профиля. Очистка данных браузера удаляет прогресс; синхронизации и регистрации нет. При недоступности записи приложение показывает ошибку.

«Не помню» — через 10 минут; «С трудом» — через 1 день; «Легко» — сначала через 3 дня, затем удвоение до 60 дней. Термин считается изученным после оценки «С трудом» или «Легко»; новая оценка «Не помню» снимает этот статус. Техника повторяется через 3 дня после ручной отметки. Это самооценка, а не подтверждение качества исполнения.

Короткое занятие включает до четырёх терминов (сначала просроченные, затем новые) и одну тему выбранной программы. 10 минут — ориентир, принудительного таймера нет. История показывает фактически проведённое время, минимум 1 минуту. Незавершённое занятие не учитывается; уже оценённые карточки сохраняются сразу.

## Программа и материалы

В разделе «Программа» можно указать организацию, требования тренера и выбрать технические темы. Это локальная настройка демонстрационного набора, а не официальная программа аттестации.

Все технические описания являются черновиками. Перед публикацией проверенного материала тренер должен проверить название, шаги, ошибки, безопасность и видео на соответствие требованиям своей организации. В текущей версии нет проверенных видео, загрузки видео и кабинета проверяющего: карточки явно показывают «Материал готовится» и «требуется проверка тренером». Реальную проверку тренером эта версия не подменяет.

Озвучка использует Web Speech API и доступный японский голос устройства. Если голоса нет или воспроизведение не удалось, интерфейс сообщает об этом; упражнение на слух недоступно без японского голоса. Остальной сайт не требует внешних шрифтов или сервисов.

## Версия 2: путь к 10 кю

Чёрно-бело-синий интерфейс с мультяшным помощником — сенсеем Дмитрием. Учебная дорожка использует игровые принципы: последовательное открытие, обратную связь, повторение и XP. Это самостоятельное приложение, не продукт Duolingo.

В `src/curriculum.js` находятся 32 урока. В начале урока открыт блок «Заучивание» с конспектом; кнопка «К заданиям» скрывает теорию и открывает вопрос без конспекта. Все тексты также доступны в отдельном разделе «Заучивание». Урок засчитывается один раз и отмечается одной галочкой. Повторный вход открывает материал для чтения без повторной проверки и начисления XP. В конце этапов остаётся додзе кун.

Финальный тест открывается после однократного прохождения всех 32 уроков. Обязательного повторного прохождения нет. В нём 9 заданий: по 3 на японские термины, ката и историю. На ответ даётся 5 секунд, пропуск считается ошибкой. Для успеха нужно не менее 2 правильных ответов в каждом блоке. Завершённые попытки и виртуальный пояс сохраняются локально; незавершённая попытка прерывается при уходе или перезагрузке.

### XP и отдельное повторение

За первое завершение урока — +20 XP. За неверный ответ в задании урока, выборе перевода, повторении, проверке порядка додзе кун или кю-тесте — −1 XP. Пропуск по таймеру тоже стоит 1 XP. Баланс может стать отрицательным. Повторные клики по уже отвеченному заданию не списывают XP и не начисляют наград; новую попытку нужно начать явно. Самооценка карточек «Не помню» не считается проверяемой ошибкой.

Раздел «Повторение» содержит отдельную практику: японские термины и вопросы пройденных уроков. За каждые 10 правильных ответов суммарно — +5 XP. Ошибки не засчитываются в десятку и не сбрасывают уже накопленные верные ответы. Счётчик сохраняется между занятиями и после перезагрузки. История интервальных карточек и ручной план техники также сохранены; самоотметки не дают XP за правильные ответы.

Баланс хранится отдельно в `economy`. При первом запуске обновлённой версии прежние заработанные XP (включая старые награды за повтор урока) сохраняются один раз; далее действуют новые правила.

Награда сопровождается анимацией (отключается при prefers-reduced-motion). Она не присваивает 10 кю, не подтверждает исполнение ката и не заменяет очную аттестацию.

### Границы учебной программы

Полный норматив для конкретного клуба можно утвердить только после выбора организации, возраста и действующей редакции требований. Здесь приведён общий ознакомительный маршрут, а не универсальный официальный перечень: в частности, включение Тайкёку соно ити и цвет пояса нужно сверить с тренером. Практические занятия, физические нормативы, видео и проверка исполнения остаются задачей тренера. Тексты не имеют статуса одобренных тренером.

Ссылки для сверки исторических ориентиров: [IKO](https://www.kyokushinkaikan.org/en/about/) и [WKO](https://www.wko.or.jp/). В текущей облачной среде прямой доступ к этим сайтам отклонён сетевой политикой (403); актуальные редакции страниц и требования конкретной организации онлайн не проверены. Перед использованием в аттестационной программе конспекты необходимо сверить с первоисточниками и тренером.

Дополнительные тесты проверяют однократный проход 32 уроков и экономику XP, закрытие теста до выполнения условий, таймауты, отдельный порог по блокам, повторную попытку, сохранение пояса и присутствие сенсея на всех разделах — на мобильном и настольном размерах.

## Публикация на GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` запускается при отправке в `main` или вручную: **Actions → Publish GitHub Pages → Run workflow**.

Workflow устанавливает зависимости из lockfile, выполняет модульные тесты, собирает сайт с базовым путём `/karate_kiokushinkai/` и публикует `dist` через официальный механизм Pages. Локальная разработка продолжает работать от корня сайта.

Ожидаемый адрес после успешной публикации: https://5yb6wsf8vv-gif.github.io/karate_kiokushinkai/ . Результат публикации смотрите в Actions; наличие workflow само по себе не означает, что Pages включён или сайт уже опубликован. При переименовании репозитория обновите `--base` в workflow.


## Сенсей Дмитрий и игровой интерфейс

На компьютере разделы доступны в постоянной боковой панели, на телефоне — в нижней навигации. Панель сверху показывает реальные XP и число завершённых уроков; активный шаг выделен на дорожке, а кнопка продолжения ведёт к следующему непройденному уроку или повторению. Счётчиков вымышленных жизней, валюты и серий посещений нет.

Шесть портретов Дмитрия собраны в локальном PNG-атласе `src/assets/sensei-dmitry-full.png`, адаптированном по предоставленному пользователем изображению. Портреты переключаются CSS-позиционированием без обращений к внешнему сервису. Реплики и события находятся в `src/sensei.js`: верные ответы, ошибки, повторение, таймаут и завершение занятия вызывают разные реакции. Кнопка «Ещё совет» меняет реплику и настроение в рамках текущего события; в раскрывающемся списке «Эмоции сенсея» можно вручную выбрать радость, строгость, удивление, грусть, уверенность или смех. Строгие реплики остаются доброжелательными.

Смена эмоций не влияет на прогресс, XP и срок ответа в кю-тесте. Настроение временное и не сохраняется между перезагрузками. Изображение собирается Vite с корректным базовым путём для GitHub Pages. При настройке reduced motion анимация появления отключается.

## Додзе кун в конце этапа

В `src/dojo.js` сохранены семь пунктов русского текста в порядке с фотографии пользователя. Задание появляется только в финале этапов: после 8-го, 16-го, 24-го и 32-го уроков при первом прохождении этих уроков. В остальных уроках и в коротком занятии его нет.

После правильного ответа на основной вопрос завершающего урока нужно восстановить порядок всех семи фраз. Можно прочитать текст, убрать выбранные фразы, начать заново и исправить выделенные ошибки. Временного ограничения нет. Урок на границе этапа засчитывается и открывает следующий этап после правильного порядка; обычные уроки засчитываются сразу после верного ответа. Сохранённый ранее прогресс и полученный пояс не сбрасываются.

## Тёмная тема

Основная палитра тёмная, с синими акцентами и светлым текстом; переопределения находятся в `src/dark.css`. Сенсей Дмитрий изображён в полный рост в шести эмоциональных состояниях. Атлас `sensei-dmitry-full.png` имеет прозрачный фон; у персонажа нет квадратной заливки, рамки, скругления или тени иконки. Механика уроков, таймер и сохранённый прогресс не меняются.

## Эстафеты этапов

После восьми уроков каждого этапа открывается дополнительный урок «Эстафета»: 10 заданий, по 10 секунд на сборку порядка изображений. В `src/relay.js` находятся 40 учебных связок и схематические SVG-иллюстрации фаз движения. Это демонстрационные связки кихон, не норматив конкретной организации и не проверенная тренером методика исполнения. Перед запуском можно открыть блок заучивания последовательностей.

Во время задания выбранные карточки можно убрать и переставить. Первая проверка или истечение срока фиксируют окончательный ответ. Исправление ответа, повтор задания и повтор всей завершённой эстафеты недоступны. До следующего задания пользователь переходит отдельной кнопкой; отсчёт следующего начинается только тогда. Проходной результат — не менее 7 из 10. Ошибка или пропуск списывает 1 XP.

Ответы, порядок выбранных карточек, срок текущего задания и итог сохраняются в `course.relays`. Выход из эстафеты через маршрут или навигацию, перезагрузка и закрытие страницы окончательно прерывают начатую попытку: `aborted=true`, `done=true`, `passed=false`, без продолжения и нового старта. Даже 7 верных ответов до выхода не засчитывают незавершённую эстафету. Уже завершённые результаты сохраняются. Простое переключение вкладки не завершает попытку, но таймер продолжает идти. Незавершённые попытки прошлой версии закрываются при следующем запуске приложения. Эстафеты добавлены к этапам отдельно от прежних 32 уроков, не сбрасывают старый прогресс и не меняют доступ к следующему этапу или кю-тесту: неудачная единственная попытка не блокирует весь курс навсегда.


### Сенпай Жанна на эстафете

Во всех состояниях эстафеты вместо Дмитрия используется Жанна: прозрачный атлас `src/assets/senpai-zhanna-full.png` с шестью эмоциями в полный рост, адаптированный по изображению пользователя. Между заданиями и на результатах портрет полный, в задании с таймером — компактный, с сохранением всей фигуры и без рамки. Правильные ответы, ошибки, таймауты и результат меняют её эмоции и реплики. На вступлении и результатах доступны ручная смена эмоций и «Ещё совет». Реплики Жанны учитывают единственную попытку и не предлагают повторить закрытое задание. В остальных разделах остаётся Дмитрий.

## Онлайн-поединки

Сервер и инструкция публикации находятся в [multiplayer/README.md](multiplayer/README.md), конфигурация Render — в `render.yaml`.

Локальный запуск сервера: `ALLOW_LOCAL_ORIGINS=true PORT=3001 npm run duel:server`. После запуска Vite откройте раздел «Поединок» и укажите локальный адрес API. В опубликованном сайте используйте HTTPS-адрес Render. Приглашение включает публичный адрес сервера и код комнаты, поэтому второй игрок может подключиться с другого устройства. Персональный токен игрока хранится только в sessionStorage и не включается в ссылку.

Сервер определяет первого правильно ответившего и выдаёт одно очко за задание. Десять заданий, до 20 секунд на каждое; при равенстве итоговых очков — ничья. Задания используют карточки упражнений: стойки, блоки, удары и перемещения. Нужно собрать четыре движения в последовательности, указанной в условии. Иллюстрации схематичные, а связки учебные и требуют сверки с тренером. Онлайн-режим не изменяет личные XP.

`npm test` включает серверные проверки. Браузерные тесты поединка запускают локальный HTTP-сервер и две изолированные сессии: проверяются десять общих заданий, итоговый счёт, ссылка-приглашение, запрет повторной отправки и выход соперника.

## Магазин скинов

Раздел «Скины» содержит три постоянных слота `skin-1`, `skin-2`, `skin-3` по 50, 100 и 150 XP. Пока используются явно обозначенные заглушки. Каталог находится в `shared/skins.js`, отображение и логика покупок — в `src/shop.js`. Будущие изображения можно добавить без изменения идентификаторов: купленные слоты и выбранный образ сохранятся.

Покупка списывает XP один раз и автоматически выбирает скин. Купленный скин можно выбирать бесплатно; базовая аватарка всегда доступна. Недостаток XP блокирует покупку. XP и коллекция записываются одной операцией вместе с прогрессом в localStorage; при ошибке записи покупка откатывается. Учётная запись и перенос между устройствами отсутствуют.

При создании комнаты или входе в неё клиент отправляет выбранный `skinId`. Сервер принимает только известные идентификаторы и передаёт аватарки обоим игрокам во всех состояниях поединка. Неизвестные идентификаторы и старые клиенты получают базовую аватарку; внешние пользовательские URL не принимаются. Скины не влияют на счёт. Покупки относятся к локальному прогрессу: сервер без регистрации не проверяет подлинность заработанных на устройстве XP.

После обновления frontend нужно обновить и перезапустить сервер Codespaces, чтобы новые аватарки передавались сопернику. В работающем терминале нажмите Ctrl+C, затем `git pull --ff-only` и `PORT=3001 npm run duel:server`. Перезапуск удаляет текущие комнаты; создайте новую комнату. Выбор скина применяется при новом подключении к комнате.

### Вход по курсу

В «Мой аккаунт» игрок вводит имя (обязательно, до 24 символов), выбирает курс обучения 1–4 и нажимает «Начать обучение». Почта, VK ID и сервер аккаунтов не требуются. Имя и курс сохраняются вместе в localStorage (`player-profile`); ранее выбранный `player-course` подхватывается автоматически. В поединках подставляется сохранённое имя. До заполнения имени и курса отображается только стартовая настройка, в том числе при открытии прямых ссылок. Готовый профиль пропускает настройку при повторном открытии. Выход возвращает стартовый экран. Это локальный профиль: курс не подтверждает личность, прогресс не разделяется между игроками и не синхронизируется. Смена курса и выход не очищают учебный прогресс или покупки.

Прежний серверный модуль авторизации сохранён как неиспользуемый задел; его настройка для текущего интерфейса не нужна. Переменная ENABLE_AUTH по умолчанию выключена.

### Установка как приложения (PWA)

Откройте опубликованный сайт с интернетом. В «Мой аккаунт» (и на стартовой настройке) есть блок установки и статус сохранения материалов.

- Android / Chrome: нажмите «Установить приложение», когда браузер предложит установку, либо выберите её в меню браузера.
- iPhone / iPad: откройте сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить».
- Компьютер: кнопка установки в адресной строке Chrome/Edge; в Safari на Mac — «Файл» → «Добавить в Dock».

После первого успешного сохранения доступно повторное открытие приложения без интернета: 32 урока, термины, повторение, техника и скины. Первое открытие требует сети, приложение загружает около 5 МБ материалов. Прогресс и профиль остаются в локальном хранилище. Озвучка зависит от японского голоса устройства и его доступности без сети. Поединкам всегда нужны интернет и работающий сервер; API-ответы и токены серверов не кэшируются сервис-воркером.

При выходе новой версии появляется кнопка «Обновить приложение». Автоматического прерывания урока нет: обновление доступно после выхода из занятия/поединка. Перезапуск при обновлении сохраняет записанный прогресс. Установка сама по себе не переносит профиль между устройствами; на некоторых устройствах установленная копия может использовать отдельное хранилище. Удаление данных браузера/приложения может стереть локальный прогресс и офлайн-копию.

GitHub Pages и HTTPS подходят для установки; отдельный магазин приложений не требуется. `vite.config.js` генерирует manifest и service worker с учётом `--base /karate_kiokushinkai/`; сервер поединков менять не нужно. В разработке service worker отключён, чтобы не мешать изменениям. Проверка сборки с настоящим service worker, офлайн-перезапуска, иконок, исключения API из кэша и обновления: `npm run test:pwa` (использует production preview на порту 4175).

### История киокушинкай

Раздел содержит шесть хронологических вех, восемь раскрывающихся тем и восемь карточек для самостоятельного вспоминания; чтение не начисляет и не списывает XP. Данные и представление: `src/history.js`. Биографические сюжеты и символические толкования обозначены как изложение источника; экстремальные тренировочные предписания не переносятся в программу начинающих.

Дополнены тексты уроков 3–5, сохранены их идентификаторы, ответы и общее число 32. Из исторических уроков есть переход к расширенному материалу. Раздел входит в офлайн-сборку PWA. Проверки: `tests/browser/history.spec.js`, офлайн-сценарий в `tests/pwa/pwa.spec.js`.

В публичном разделе истории и текстах уроков убраны внешние ссылки и формулировки о сайте/статье. Происхождение адаптированного материала указано выше в документации проекта. Основной текст увеличен до 17–18 px; оформление дополнено линиями татами, энсо, японскими знаками на карточках и блоком ценностей карате. Чтение не меняет учебный прогресс и XP.

На телефоне доступные упражнения показаны сеткой 2×2, выбранные — компактными карточками, таймер закреплён при прокрутке. Для следующих раундов экран возвращается к условию. Тексты и иллюстрации входят в офлайн-сборку, онлайн-матч требует подключения к API.

### Видео техники

В карточках техники и десяти движениях кихон доступен экран «Повторяй за тренером»: локальный видеофайл, отсчёт перед стартом, скорость, зеркальное отображение и повтор. Просмотр не начисляет XP и не подтверждает правильность исполнения. Выбранный файл не отправляется на сервер и освобождается при закрытии урока.

По предоставленной пользователем ссылке подключён YouTube-ролик `y4r1qAHXHwI` для сэйкэн моротэ-цуки: общий ролик доступен у трёх уровней кихон (`kihon-0` … `kihon-2`). YouTube загружается после отсчёта; скорость регулируется в самом плеере, зеркальный режим и автоматический повтор доступны для локальных видео. Воспроизведение на YouTube из среды разработки проверить нельзя; браузерный тест проверяет встраивание с подменённым плеером. Остальные ролики со страницы https://kontakt-karate.ru/online/tehnika-kyokushinkai-10-kyu пока не подключены: страница недоступна из среды разработки, адреса не получены. Проверенные MP4/WebM-адреса можно добавить в `lessonMedia` в `src/video-lessons.js`, например `{zenkutsu: {url: 'https://…/lesson.mp4', attribution: '…'}}`. Ключи существующих карточек сохранены; ключи кихон — `kihon-0` … `kihon-9` по порядку программы. Для YouTube используется запись `{youtube: 'идентификатор ролика', attribution: '…'}`; ссылки на страницы VK не являются прямыми видеофайлами и требуют отдельной интеграции плеера. Подсказки сейчас показываются рядом с видео; точную синхронизацию движений можно разметить после получения роликов. Браузерные проверки используют небольшой тестовый WebM в `tests/fixtures`.

#### Загруженный учебный фрагмент

`IMG_1100.MOV` (28,51 с) преобразован из HEVC в H.264/AAC MP4 1280×720; обработанная версия с силуэтом и контурами: `public/videos/taikyoku-gentle-mask.mp4`. Исходный файл и его метаданные не публикуются. В разделе техники отдельная кнопка открывает «Тайкиоку соно ичи». Название ката подтверждено пользователем; запись заканчивается во время выполнения. Подсказки размечены по визуальному просмотру кадров в `src/follow-timeline.js`, привязаны к `video.currentTime`; это учебная разметка, требующая проверки тренером. Иллюстрации обозначают тип движения, без назначения левой/правой стороны. Локальная замена ролика отключает эту разметку, чтобы не показывать чужие подсказки. MP4 не включён в обязательный офлайн-кэш PWA; для загрузки нужен интернет. Исполнение не оценивается и автоматически не отмечается пройденным.


#### Силуэт и виртуальное татами

В уроке публикуется обработанная версия: светлый силуэт человека с бирюзовым внешним контуром и внутренними линиями одежды и перекрытий конечностей, тёмная арена и нарисованное перспективное татами. Фон исходного зала полностью заменён; фигура стабилизирована по положению таза и высоте. Изменение не зеркалит движения. Первые 855 кадров (около 28,5 с) сохраняют последовательность исходных движений. Затем добавлены 1,2 с монтажного растворения в первый кадр и 1,5 с удержания начальной стойки; это не реконструкция отсутствующего выхода из ката. Общая длительность — около 31,2 с. Новые подсказки обозначают переход и начальную стойку. Исходный звук полностью удалён; новая дорожка содержит только синтезированные эффекты движения воздуха и удара, без речи и музыки. Начало и добавленное окончание без звука. Маска выделялась автоматически MediaPipe Pose (0 пропущенных масок); это не ручная покадровая обтравка, возможны небольшие колебания контура и потеря тонких деталей. Уже обрезанные камерой части фигуры не восстанавливаются.

Повторный рендер: установите `mediapipe==0.10.21` в отдельное Python-окружение и используйте `python scripts/render-silhouette.py /путь/к/исходнику.mp4 public/videos/taikyoku-gentle-mask.mp4`. Нужен FFmpeg. Эти зависимости требуются только для обработки видео; сборка приложения их не использует. В `public/videos` исходная запись заменена обработанным роликом. Внутренние линии извлечены из реальных кадров (Canny по сглаженному изображению) и ограничены маской фигуры, без дорисовки скелета; мелкие детали лица исключены. Для сохранения кистей и стоп используются также близкие небольшие компоненты маски. Смягчение края ограничено, чтобы различались движения рук и ног.

### Единая колода японских терминов

Базовые термины и вся программа 10 кю объединены в одну колоду из 79 карточек без отдельной панели программы. Совпадающие понятия (например, Ос, Рэй, Фудо-дачи) представлены общей карточкой; полные дополнительные пояснения сохранены. Доступны фильтры темы, «Базовые термины», «Пора повторить», карточки, выбор перевода и упражнение на слух. Колода используется также в коротких занятиях, повторении и статистике.

ID первых десяти терминов сохранены. Миграция `migrateTermProgress` переносит прежние ID-дубликаты `p10-*` к общим ID, суммирует число повторений и сохраняет последнюю оценку по вычисленному времени занятия. Остальные `p10-*` не меняются. Миграция идемпотентна; профиль, XP, курс и отметки техники не сбрасываются.

Японские написания и явные чтения каной находятся в `src/japanese-terms.js`. Открытый словарь JMdict получен через `jamdict-data==1.5` (EDRDG, CC BY-SA 3.0); прямые словарные совпадения и чтения записаны в `public/audio/japanese-sources.json`. Совпадения найдены у 63 из 79 карточек; остальные — составные названия техник или формы команд, а не отдельные словарные статьи. Не все японские названия записываются только иероглифами: сохранены нормативные формы с каной. Русские транскрипции пользователя сохранены; озвучивается японское чтение, а не русская запись.

Для всех 79 карточек включены готовые MP3 (суммарно меньше 1 МБ), синтезированные Open JTalk / pyopenjtalk-plus 0.4.1.post10 с открытым голосом Mei, Nagoya Institute of Technology / MMDAgent, CC BY 3.0. Это синтез речи, не записи инструктора. Файлы воспроизводятся без установленного японского голоса устройства и входят в офлайн-кэш PWA. При ошибке загрузки приложение пробует японский системный голос; если и он недоступен, показывает ошибку. Переход к другой карточке и выход со страницы останавливают звук. Источники и лицензии доступны из раздела терминов и в `public/audio/LICENSE.txt`.

Повторная генерация: экспортируйте `terms` из `src/data.js` в JSON и запустите `scripts/generate-japanese-audio.py terms.json public/audio/ja` в отдельном Python-окружении с `pyopenjtalk-plus==0.4.1.post10` и FFmpeg. В аудио подаётся явная кана, чтобы синтезатор не угадывал чтение редких сочетаний. Эти инструменты нужны только для подготовки MP3 и не устанавливаются при сборке приложения.


#### Чёткие контуры и эффекты ударов

Текущая версия — `public/videos/taikyoku-gentle-mask.mp4`. Убраны Gaussian blur альфа-маски, внешнее свечение и временное сглаживание сегментации. Внутренние линии извлекаются из кадров 1280×720, внешняя обводка сделана тонкой и слабоконтрастной, а внутренние линии складок ослаблены. Для плеча/локтя/запястья используется сплошная геометрическая поддержка маски без отсева по цвету рукава или кожи, чтобы сохранить предплечье и кисть при быстром выпрямлении. Это автоматическая обтравка, а не восстановление деталей, которых нет из-за смаза исходной камеры; возможны мелкие неровности.

`render-silhouette.py` теперь выпускает видео без исходной аудиодорожки. `scripts/add-strike-audio.py` создаёт 12 коротких звуков из фильтрованного шума и затухающего тона, затем добавляет только эту дорожку. Сэмплы не скачиваются. Время эффектов (`impactTime`) размечено отдельно от начала подсказки в `src/follow-timeline.js`. При повторной генерации экспортируйте `trainingClip.cues` в JSON и запустите `python scripts/add-strike-audio.py silent.mp4 public/videos/taikyoku-gentle-mask.mp4 cues.json`. Скрипту нужен NumPy и FFmpeg.


#### Непрерывная маска рук

Рендер выполняет предварительный проход трекинга суставов по всему исходнику. `scripts/arm_mask.py` восстанавливает краткие пропуски уверенного трекинга (до 6 кадров, около 0,2 с) линейной интерполяцией координат между соседними наблюдениями. Длинные невидимые интервалы не интерполируются. Затем цепь плечо → локоть → запястье и видимые кончики пальцев формируют сплошное покрытие, объединяемое с маской тела независимо от цвета пикселей. Пиксели соседних видеокадров не смешиваются: шлейф не добавляется. Это всё ещё автоматическая оценка положения по исходной записи, а не ручная обтравка или смена ракурса. Проверки связности вытянутой руки и ограничения интерполяции запускаются через `python scripts/test_arm_mask.py` в окружении инструментов видео.


#### Прежний силуэт с менее агрессивным удалением фона

По запросу пользователя возвращена обработка до ручных опорных точек и дополнительных границ поверх рук. Внешний контур сохраняет прежний цвет с менее сильным смешиванием (70%); внутренние линии ограничены основными складками: Canny 85/165, отсев штрихов короче 18 пикселей, без утолщения, интенсивность 65%.

Удаление фона ослаблено: общий порог маски снижен с 0,28 до 0,18, в ограниченной области возле рук сохраняются исходные пиксели с уверенностью выше 0,008. Короткие разрывы соединяются морфологическим замыканием. Мелкие компоненты кистей рядом с фигурой сохраняются. Это расширение отбора реальных пикселей, без последних ручных поправок положений кистей и без новых внутренних геометрических контуров. Возможны остатки фона по краям неопределённых участков — более мягкая маска предпочитает сохранить руку. Звуковые эффекты и монтажный возврат к стойке сохранены.
